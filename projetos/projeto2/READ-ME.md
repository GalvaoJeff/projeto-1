#GAME LOTR BATTLE#

Antes de executar o jogo rode este código abaixo no terminal (se linux):

sudo apt install ffmpeg

----------------------------

Para executar o game, acesse a pasta onde esta o arquivo "index.php" e execute o arquv no terminal:

pgp index.php

-----------------------------

Personagens:

Warrior - Aragorn
Wisard - Gandalf
Archer - Legolas
Berseker - Ork



-----------------------------

Cada personagem pode:

1 - Atacar;
2 - Defender;
3 - Descansar (recuperar Stamina);
4 - Usar Ataque Poderoso (Com maior dano);
5 - Usar Ataque Especial;


---------------------------------

Especial Aragorn:

Inflinge dano maior e aumenta sua defesa

---------------------------------

Especial Gandalf:

Aumenta o HP (Cura)

---------------------------------

Especial Legolas:

Dano maior e flexa envenenada por 3 turnos

---------------------------------

Ork:

Dano maior e sangramento por 3 turnos

---------------------------------
